# マキちゃんのモンスターアドベンチャー

制作済みの7章ストーリーを引き継いだブラウザRPGです。

- メイン: https://fuzzysetts515-eng.github.io/maki-monster/
- キョウブツが最初から仲間の旧版: https://fuzzysetts515-eng.github.io/maki-monster/classic/
- 当初の公開版: https://fuzzysetts515-eng.github.io/maki-monster/original/

## 遊び方

矢印・WASDで移動、Z・Enterで決定、Escでメニュー。スマートフォンは画面の方向ボタンと決定ボタンを使用します。横向きでは操作盤を左右に配置し、中央を冒険画面に使います。

タコットから冒険を始め、7地域を巡って仲間を増やします。キョウブツは海賊船ホイル号の渦潮イベントで対戦後、Lv45で加入します。章を進める会話とエンディングは元のストーリー版を保持しています。

回復地点・イベントの終了・メニューの「きろくする」で保存。タイトルの「つづきから」で同じブラウザの記録を再開します。記録は端末内のlocalStorageに保存され、別端末とは同期しません。保存不可の場合はメニューに表示します。

控えも経験値を獲得します。クリアした地域ではメニューから再戦練習ができ、経験値と購入用のお金を得られます。進行中の目標・ことりとの出会い・新聞取材の記録をメニューで確認できます。

## 検証範囲

Nodeの模擬DOMで全7章のシーン・選択分岐・加入・エピローグ、各章の保存再開、敗北復帰、実戦のターンとPP消費、3種のボス戦、進化、二重操作、不正セーブ、全マップのNPC・渦潮への到達性を確認。

シーン試験は戦闘勝利を強制して物語の進行を検査し、ボス戦試験は章相当の仲間編成と固定乱数で別に実行しています。これは最初から最後までの実機プレイ試験ではありません。iPhone実機の表示・音声・タッチの最終確認は別途必要です。


## 操作・戦闘バランスの追加修正

- 横持ちの配置を幅600px未満にも適用。回転、表示領域の高さ変更、安全領域に追従します。「画面を広げる」は対応ブラウザの全画面表示を使い、非対応時は横持ちの案内を表示します。
- 移動を一つの描画ループで補間し、タイル間の待ち時間を解消。指を離す・キャンセル・画面切替時に入力を解除し、壁とイベントは1マスずつ判定します。
- ゲーム内のピンチ・ダブルタップによる誤拡大を抑制。メニューの縦スクロールは維持します。
- 序盤カイザ戦はLv8、技と能力を調整し、元のブラッキーが主人公を守ります。終盤カイザ戦はLv44/48。ボスの自己回復は各個体2回まで、まひには持続ターンと再付与保護を設けました。
- 章移動で仲間の最低レベルを5/8/16/24/32/40/46に補完。既に育てた高いレベルは下げません。道中の経験値・進化・技習得は継続します。旧セーブにも現在地の補完を適用します。
- 第3章の野生は上限Lv16、発電所停止後はLv14。メニューでメラメラン、Lv18のじならし、回復所を案内します。
- 元の全画像、BGM、7章のシーン関数とエピローグ、旧版URLを維持しています。

### 追加検証の条件と結果

実際のHeadless Chromeで844×390、852×393、390×844、568×320、844×300を描画し、画面外へのはみ出しがないこと、キー解放・タッチキャンセル後の停止、ピンチ後の倍率1を確認しました。iPhone Safari実機での確認ではありません。

序盤カイザ戦は初期タコットLv5〜6、既存のブラッキーLv12、きずぐすり3個を持ち、HP半分未満で回復する条件。任意の野生戦0/3/6回の各40試行、計120試行で勝利し、平均使用数は0.65〜0.85個でした。敵HPの書き換え・強制勝利は使っていません。

全編は実際の戦闘処理で検証。既存NPCの贈り物、所持金内の薬購入、無料回復所、発電所停止、電気の町でメラメランを先頭にする行動を使用。各地域3戦・毎戦回復で20/20回、6戦で40/40回クリア。寄り道なしは26/40回。出現種・レベルを抽選し、道中3連戦の間は回復所へ戻らない条件は34/40回クリアで、6回は道中の消耗で敗北しました。相性・育成・回復を無視しても勝てる設定ではありません。装備システムはなく、回復アイテムと技選択をモデル化しています。

全7章の分岐・保存再開・進化・敗北後再開、音の設定、画像/BGM一致、入力所有権、壁とイベント順序も回帰確認済み。シーンの分岐テストだけは戦闘勝利を強制し、上記の実戦バランス検証と分けています。
